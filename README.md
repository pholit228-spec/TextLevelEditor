# Text Level — Geode-мод для Geometry Dash

Пишешь уровень текстом (его может написать ИИ) → мод строит объекты, триггеры, цвета, фон и музыку прямо в редакторе.

## Сборка
1. Залей содержимое архива **в корень** репозитория (`.github/workflows`, `mod.json`, `src`, … прямо в корне).
2. `git add . && git commit -m "init" && git push` — GitHub Actions соберёт мод (Windows, Android32, Android64).
3. Скачай артефакт `Build Output` → файл `.geode` → положи в папку `geode/mods`.
   Если сборка ругается на версию Geode — впиши в `mod.json` (поле `geode`) ту версию, что указана в ошибке.

## Использование
В редакторе уровня слева появятся 4 кнопки (позицию можно поменять в настройках мода):
- **Paste** — выполнить скрипт из буфера обмена (скопируй ответ ИИ и нажми).
- **File** — выполнить `level.txt` из папки сохранений мода (при первом запуске там лежит пример; путь показывает кнопка Help).
- **Dump** — скопировать весь текущий уровень в буфер как скрипт (чтобы показать ИИ, что уже есть).
- **Help** — краткая справка по командам.

Полный язык для ИИ: `docs/AI_GUIDE.md` — отправь файл ИИ вместе с заданием.

## Заметки
- Настройки уровня (фон, земля, песня, старт-режим…) применяются, если такое поле есть в твоей версии GD/Geode; иначе скрипт сообщит «setting not available», остальное работает.
- Сохрани уровень и перезайди в редактор, чтобы увидеть смену фона/земли.
